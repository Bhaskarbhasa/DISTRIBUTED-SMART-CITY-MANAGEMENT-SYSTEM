# Viva Questions & Answers

## Distributed Systems Basics
**Q1: What is a distributed system?**
A: A system whose components are located on different networked computers, communicating and coordinating actions by passing messages to appear as a single coherent system.

**Q2: Why use a distributed system here?**
A: For scalability, fault tolerance, and reduced latency via edge/fog computing.

**Q3: What is Event Sourcing?**
A: Storing state as a sequence of events rather than just the current state.

## Raft/Consensus
**Q4: What is the Raft algorithm?**
A: A consensus algorithm for managing a replicated log, designed to be easy to understand.

## CAP Theorem
**Q5: What does CAP stand for?**
A: Consistency, Availability, Partition Tolerance.
